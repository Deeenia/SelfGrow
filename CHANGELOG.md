# Changelog

All notable changes to SelfGrow are documented here.

## 0.1.0 - 2026-09-05

### Added

- Local-first capture for URLs, shared text, images, attachments, and GitHub repositories.
- Explicitly authorized PDF and Markdown document extraction and AI summarization.
- Mobile-compatible Raw review, categorization, selection, and deletion flows.
- Optional AI-generated titles, previews, visual understanding, and preference-based recommendations.
- Protected, approval-gated Wiki distillation through the bundled `selfgrow-wiki` skill.
- SecretStorage-backed provider keys and explicit third-party extraction disclosures.

### Verified

- Windows desktop and iOS installations tested against the same production bundle.
- Formatting, lint, type checking, 364 automated tests, and production build passed.
- Production dependency audit reported no known vulnerabilities.
