# 深层偏好协议如何运作

SelfGrow 保留用户在设置中选择的“感兴趣 / 不感兴趣”关键词，并可额外读取一个经过用户审核的深层偏好协议。插件不会扫描 Codex 历史或 Vault 外的项目。

当用户要求生成或更新协议时，`selfgrow-wiki` Agent Skill 只读取用户明确授权的项目摘要，生成带来源摘要哈希和权重的候选协议。Skill 先校验并展示完整内容；只有用户明确批准后，才写入 Raw 目录同级的 `Preferences/preference-profile.json`。

生成新卡片时，模型先根据当前材料和关键词给出基础推荐度，并返回命中的协议规则 ID。插件拒绝协议中不存在的 ID，然后把已批准规则的权重应用到基础分并限制在 `0–100`。卡片保存关键词命中、协议命中、通用协议版本和个人协议版本。协议缺失、关闭或格式错误时，会自动退回关键词评分；更新协议只影响之后生成的卡片。
