# 个人偏好协议如何运作

SelfGrow 只维护一份 Vault 本地个人偏好协议：Raw 目录同级的 `Preferences/preference-profile.json`。设置中的“感兴趣 / 不感兴趣”主题不是另一套评分器；点击保存会把它们写成协议内权重为 `+8 / -8` 的手动信号，并生成新的 `profileVersion`。

也可以由 `selfgrow-wiki` Agent Skill 先创建协议。Skill 只读取用户明确授权的项目摘要，生成带来源摘要哈希和权重的候选协议，先校验并展示完整内容，只有用户明确批准后才写入。两种顺序都受支持：主题可以先创建基础协议，再由 Agent 加入项目偏好；Agent 也可以先创建基础协议，再由主题选择补充手动信号。插件更新时保留 Agent 信号和来源，Agent 更新时必须保留插件管理的手动信号。

生成新卡片时，插件把完整协议中的正向偏好、负向偏好、名称、权重和说明提供给模型，但不会发送内部 ID、来源项目名、路径或摘要记录，也不会再发送独立关键词结构。模型综合当前材料与协议，直接给出 `0–100` 推荐度及一句理由；命中的偏好仅以人类可读名称展示，不作为评分有效性的门槛。

标题、分类和预览与推荐字段分开校验。推荐字段错误只会隐藏分数并显示“偏好协议评分未生成”，不会使链接、文本或纯图片收集失败。个人协议缺失、停用、无效或没有任何信号时不生成推荐度。卡片保存实际使用的通用协议版本和个人协议版本；更新协议只影响之后生成的卡片，不会静默改写历史卡片。
